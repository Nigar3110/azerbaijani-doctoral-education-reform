# Why Reform Does Not Become Transformation: Asymmetric Morphogenetic Agency and Systemic Transformation in Azerbaijani Doctoral Education

Code and survey data supporting the paper "Why Reform Does Not Become Transformation: Asymmetric Morphogenetic Agency and Systemic Transformation in Azerbaijani Doctoral Education."

## Overview

This repository contains the survey data and analysis notebooks used to study doctoral students' academic experience (financial satisfaction, supervision quality, access to research resources, psychological/social support, and work–life balance) and supervisors' perspectives on doctoral supervision, in the context of doctoral education reform in Azerbaijan.

## Repository structure

```
.
├── data/
│   ├── students\_survey.csv      # doctoral student survey responses (n=300)
│   └── supervisor\_survey.csv    # supervisor survey responses (n=123)
├── notebooks/
│   ├── 01\_data\_collected.ipynb              # initial data compilation, specialty/funding cross-tabs
│   ├── 02\_rectors\_survey.ipynb              # rector-level survey analysis (funding, program size)
│   ├── 03\_students\_survey.ipynb             # student survey cleaning and descriptive analysis
│   ├── 04\_student\_clusters.ipynb            # clustering: financial satisfaction vs. support access
│   ├── 05\_student\_clusters\_wellbeing.ipynb  # clustering: well-being, research access, financial satisfaction
│   └── 06\_supervisor\_analysis.ipynb         # supervisor survey analysis
├── figures/                      # output plots generated by the notebooks
├── requirements.txt
├── LICENSE
└── CITATION.cff
```

## Data

Both survey files are anonymized (no names, emails, or other direct identifiers). Some original survey questions were written in Azerbaijani; several notebooks rename these columns to English working names during analysis (e.g., `Support\_access`, `Well\_being`, `Financial Satisfaction`).

* **`students\_survey.csv`** — doctoral student responses covering specialty, education year, study form, employment status, financial satisfaction, access to psychological/social support, access to research resources/infrastructure, supervision quality/frequency/clarity, and work–life balance.
* **`supervisor\_survey.csv`** — supervisor responses covering institution type, research field, years of supervision experience, number of doctoral students supervised, supervision practices, institutional support, and views on AI tool usage in doctoral supervision.

Institutions involved in data collection include Azerbaijan State Oil and Industry University, among others; see the paper for full sampling details.

## Setup

```bash
pip install -r requirements.txt
jupyter notebook
```

Notebooks are numbered in a suggested run order. Each notebook reads its input from `../data/` and writes any figures to `../figures/`, so run them from within the `notebooks/` directory (or adjust paths if running from elsewhere).
